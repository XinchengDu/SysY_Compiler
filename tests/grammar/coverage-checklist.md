## 一、所有测试程序的共同要求

- [ ] `case` 常量类型与 `switch` 表达式类型一致

```c

```

```c

    default:

}
```

```c
char letter = 'A';

switch (letter) {
    case 65: // 类型不匹配
        break;
}
```

## 4.2 短路求值

可以使用全局变量记录函数调用次数：

```c
int counter = 0;

int change() {
    counter = counter + 1;
    return 1;
}
```

### 情况一：`0 && 右侧`

```c
if (0 && change()) {
    ;
}
```

- [ ] 右侧函数没有执行
- [ ] `counter` 没有增加

### 情况二：`1 && 右侧`

```c
if (1 && change()) {
    ;
}
```

- [ ] 右侧函数执行
- [ ] `counter` 增加一次

### 情况三：`1 || 右侧`

```c
if (1 || change()) {
    ;
}
```

- [ ] 右侧函数没有执行
- [ ] `counter` 没有增加

### 情况四：`0 || 右侧`

```c
if (0 || change()) {
    ;
}
```

- [ ] 右侧函数执行
- [ ] `counter` 增加一次

### 验证输出

- [ ] 每次短路测试后输出 `counter`

```c
printf("%d\n", counter);
```

- [ ] `outputN.txt` 中的结果能证明是否发生短路
- [ ] 不仅检查条件结果，还检查右侧表达式是否执行
